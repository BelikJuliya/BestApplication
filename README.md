Тестовое задание для компании "Лучшее приложение". Приложение со списком фильмов.
1. Bottom Navigation с двумя вкладками: все фильмы и сохраненные фильмы
1. Экран со списком фильмов в виде карточек в два ряда. Фильмы получаются по API и кешируются в БД Room.
2. Экран со списком сохраненных фильмов
3. Splash Screen
4. Возможность фильтровать фильмы по популярности / алфавиту / рейтингу / количеству оценок
5. Возможность удалять сохраненные фильмы
6. Экран с дподробным описанием фильма, актеров и тд

Приложение реализовано на XML с помощью Adapter Delegates + List Adapter. В приоложении используется чистая архитектура с разделением на модули по слоям. Данные берутся из разных дата сорсов (локальный и удаленный). Архитекта MVI.
В ТЗ было указано отказаться от использования библиотек, поэтому DI организован вручную через конструктор, а для навигации используется Fragment Manager.

API используемое для приложения стало недоступно, поэтому список фильмов на скриншотах отсутствует, вместо него отображается заглушка.
